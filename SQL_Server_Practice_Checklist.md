# Practice Checklist

After running the main SQL script, practice these topics in SSMS:

1. SELECT / WHERE / ORDER BY
2. INNER JOIN
3. LEFT JOIN
4. GROUP BY / HAVING
5. Aggregate functions: COUNT, SUM, AVG, MIN, MAX
6. Subqueries
7. CTE
8. CASE
9. INSERT / UPDATE / DELETE
10. Stored Procedures
11. Views
12. Function
13. Trigger
14. Transactions and rollback
15. Indexes
16. Actual Execution Plan (Ctrl+M)
17. Backup / Restore
18. SQL Server Agent (create a scheduled backup job later)
19. Users / Roles / Permissions
20. Query optimization
